# Резервное копирование D1 на Windows

scripts/backup-at-home.ps1 вызывает зашифрованный переносимый экспорт D1 scripts/d1-backup.mjs, проверяет его и атомарно копирует по SHA-256 в два каталога: ~/OneDrive/Atelier-D1-Encrypted-Backups и K:/Atelier-D1-Encrypted-Backups.

Ежедневный запуск в 08:30 по местному времени через scripts/install-backup-task.ps1, когда ПК включён и пользователь вошёл в Windows. Планировщик повторяет пропущенный запуск при следующей возможности. Статус: %LOCALAPPDATA%/Atelier-D1-Backup/last-status.json без SQL/контактов/секретов.

**Ограничение:** файл в каталоге OneDrive НЕ доказывает синхронизацию в облако. При остановленном клиенте — PARTIAL_LOCAL, код 2; при запущенном — COPIES_VERIFIED_REMOTE_UNCONFIRMED до проверки. Архивы защищены AES-256-GCM. Ключ в ~/.atelier-secrets/backup-passphrase.txt. Ключ обязательно следует самостоятельно сохранить в безопасном хранилище вне ПК, отдельно от архива. Не отправлять ключ и SQL в GitHub/чаты.

SelfTest использует синтетические данные, не трогает производственную БД. Для аварийной готовности нужны отдельная проверка облачной копии, свежести и регулярные восстановления в тестовую D1.
