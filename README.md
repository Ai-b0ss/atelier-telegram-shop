# Atelier Telegram Shop — бот для авторской одежды

Учебный, но запускаемый MVP продажи авторской одежды через Telegram: **каталог → корзина → оформление заказа**, индивидуальные заявки на пошив, административные статусы, ручной учёт финансовых операций и Excel-отчёты.

## Возможности

- Категории, товары, размеры, цвета и складские остатки; фотографии по Telegram `file_id`, если указаны в базе.
- Корзина с проверкой наличия и атомарным оформлением заказа (SQLite).
- Заявки на индивидуальный пошив с мерками и пожеланиями.
- Администраторские команды для статусов, смет, записи оплат и возвратов.
- Excel (.xlsx): сводные показатели, заказы, платежи, остатки и учётная себестоимость.
- 13 автоматических тестов для финансов, остатков, возвратов, гонок и выгрузки.

## Запуск

Требуется **Python 3.11+** и токен Telegram от @BotFather.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`. Заполните **BOT_TOKEN**, **ADMIN_IDS** (Telegram ID администратора через запятую), при желании **DATABASE_PATH**. Переменные из `.env` нужно загрузить в окружение, например:

```bash
# Linux/macOS:
set -a; source .env; set +a
python -m atelier.seed
python -m atelier
```

Windows PowerShell:

```powershell
Get-Content .env | Where-Object { $_ -match '^[A-Z_]+=' } | ForEach-Object {
  $key,$value = $_ -split '=',2
  [Environment]::SetEnvironmentVariable($key,$value,'Process')
}
python -m atelier.seed
python -m atelier
```

Или через Docker Compose (после создания `.env`):

```bash
docker compose run --rm bot python -m atelier.seed
docker compose up -d --build
```

**Важно:** демонстрационные товары вымышленные. Перед продажей замените ассортимент и цены в SQLite, укажите администратора и настройте хостинг для круглосуточного запуска. Для изменения каталога предусмотрена консольная утилита `python -m atelier.manage` (см. ниже), графической админ-панели пока нет.

## Настройка каталога

```bash
python -m atelier.manage list
python -m atelier.manage category "Платья"
python -m atelier.manage product 4 "Платье с вышивкой" "Лён, ручная вышивка"
python -m atelier.manage variant 4 DRESS-S-BLUE S синий 9500 4200 5
python -m atelier.manage stock 4 7
python -m atelier.manage deactivate 4
```

Числа `4` — примеры идентификаторов: после создания посмотрите фактически возвращённый ID. Цены указываются в рублях. Загрузка фото использует Telegram `file_id`: `python -m atelier.manage photo <product_id> <file_id>`.

## Пользовательские сценарии

`/start` → категории → изделие → размер/цвет → корзина → оформление → имя, контакт, адрес / самовывоз.

`/start` → «Индивидуальный пошив» → описание → мерки → контакты → заявка. Стоимость такого заказа изначально нулевая и **не означает бесплатный пошив**: менеджер задаёт смету, после чего клиент может принять или отклонить предложение кнопкой в Telegram. Устаревшие кнопки с прежней ценой не работают.

`/cancel` прерывает ввод. «Мои заказы» показывает только заказы текущего Telegram-пользователя.

## Команды администратора

| Команда | Назначение |
|---|---|
| `/admin` | подсказка |
| `/orders` | последние 30 заказов |
| `/orders new` | заказы выбранного статуса |
| `/order 12` | детали заказа и контактные данные для менеджера |
| `/quote 12 15000 8500` | смета индивидуального заказа №12: цена и себестоимость в рублях |
| `/status 12 confirmed` | перевод заказа в разрешённый следующий статус |
| `/payment 12 received 3000` | **ручная запись** подтверждённого поступления 3000 ₽ |
| `/payment 12 refunded 3000` | **ручная запись** подтверждённого возврата 3000 ₽ |
| `/report` | Excel-выгрузка |

Статусы: `new`, `confirmed`, `in_production`, `ready`, `shipped`, `completed`, `canceled`.

**Бот не принимает реальную оплату и не переводит деньги.** Команда `/payment` вносит запись только после сверки с реальным платежом. Это важно для точности отчётов. Нельзя отменить заказ с невозвращённой оплатой.

## Финансовые показатели

- **Поступления за вычетом возвратов**: вручную внесённые операции `received - refunded`.
- **Себестоимость завершённых заказов**: сумма снимков учётной себестоимости для `completed`.
- **Ориентировочная валовая разница**: поступления минус себестоимость завершённых заказов. Это **не бухгалтерская прибыль**: показатели могут относиться к разным периодам и состояниям заказов, не включают аренду, налоги, доставку и иные расходы.
- **Стоимость неотменённых заказов**: объём принятых обязательств, **не** полученная выручка.

## Проверка

```bash
pip install -r requirements-dev.txt
python -m pytest -q
python -m compileall -q atelier
```

Для тестового прогона не требуется реальный Telegram-бот. Интеграционный запуск с Telegram требует действительный токен и доступность Telegram API.

## Безопасность и эксплуатация

- `.env` и SQLite-файлы исключены из Git. Никогда не публикуйте токен бота или реальные персональные данные клиентов.
- Не выводите отчёты и резервные копии в публичный доступ: они содержат контакты и мерки клиентов.
- Доступ к админ-командам проверяется по Telegram ID, а не по имени пользователя. Бот обрабатывает только личные чаты.
- В Excel пользовательские строки защищены от инъекции формул.
- Храните резервные копии базы и ограничьте доступ к папке `data`. Сроки хранения и согласие на обработку персональных данных необходимо определить перед реальной эксплуатацией.
- Пользовательские заказы не содержат платёжных реквизитов. Функция удаления персональных данных, онлайн-платежи, производственная калькуляция и масштабирование на несколько ботов не входят в MVP.
