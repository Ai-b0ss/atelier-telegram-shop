# Передача проекта другому агенту/разработчику

**Назначение:** Telegram-магазин авторской одежды: каталог/корзина/заказы/индивидуальные заявки, ручной финансовый учёт, Excel.

**Состояние на 31 октября 2026 года:** публичный GitHub-репозиторий https://github.com/Ai-b0ss/atelier-telegram-shop опубликован. Ветка main, история сохранена. На Windows созданы виртуальное окружение и локальная копия; 34 теста, импорт aiogram и генерация демонстрационного Excel прошли. GitHub Actions (Python 3.11, 3.12, 3.13) прошли на повторном запуске после перевода репозитория в публичный. Настоящий Telegram-бот пока не развёрнут, токен не задан.

## Структура

- `atelier/store.py` — SQLite и транзакции для заказов, резервов склада, оплаты, статусов, обезличивания.
- `atelier/bot.py` — обработчики aiogram 3, клиентская и административная часть.
- `atelier/reports.py` — выгрузка Excel, отдельные денежные показатели, защита строк от формул.
- `atelier/manage.py` — управление ассортиментом без Telegram.
- `atelier/seed.py`, `atelier/export.py`, `atelier/backup.py`, `atelier/demo.py` — демонстрационный ассортимент, автономный отчёт, резервное копирование и воспроизводимый показ системы.
- `docs/` — бизнес-процессы, BPMN, ER, инженерный отчёт, результаты тестов и развёртывание.
- `tests/test_store.py`, `tests/test_bot_offline.py` — 34 теста, включая имитацию обработчиков бота.

## Безопасность решений

- База SQLite хранит все суммы в целых копейках, цены позиций заказов фиксируются снимками, остатки проверяются под `BEGIN IMMEDIATE`.
- Деньги и возвращённые суммы записываются вручную, банковской интеграции нет; номер операции может блокировать её повторную запись. Сумма всех закрытых продаж отделена от полученных денег.
- Возврат товара на склад производится автоматически только при отмене до отправки. После отправки необходим ручной осмотр фактического возврата.
- При `/forgetme` персональные контакты, мерки и свободные комментарии к платежам из закрытых заказов обезличиваются, суммы платежей сохраняются. Старые резервные копии не очищаются автоматически.
- Административные команды защищены списком числовых Telegram ID. Все диалоги — личные.

## Проверено

- Локальная среда Python 3.13: 34/34 тестов pytest, `compileall`, Excel, проверка BPMN XML; без реальной сети Telegram.
- SQLite backup/restore и невозможность переписать существующий файл в автоматизированных тестах.
- Локальный прогон 50 полных заказов — 0,795 с на операции БД, отчёт 25,0 мс. Не является нагрузочным тестом Telegram.

## Непроверенное и незавершённое

1. В Windows-окружении aiogram установлен и успешно импортируется, но взаимодействие с настоящим Telegram API пока не проверено.
2. Для настоящего запуска нужны токен от BotFather, `ADMIN_IDS` и внешний хостинг/ПК с активным процессом.
3. GitHub CLI авторизован с разрешениями repo и workflow, использует автоматически обновляемый токен. Репозиторий публичный. GitHub Actions: https://github.com/Ai-b0ss/atelier-telegram-shop/actions/runs/41226924664 (успешно).
4. Для продакшена нужен юридический и организационный контроль обработки персональных данных, платежей, возвратов, хранения данных, а также систематические резервные копии.
