# Переход от демо к настоящему магазину — контрольный список

Обновлено 1 ноября 2026. Разрабатываемый магазин:
[@atelier_customwear_2611_bot](https://t.me/atelier_customwear_2611_bot).
Сайт: https://atelier-customwear-demo-2026.igorekglukhovskii43.workers.dev/app

## Выполнено и проверено

- Cloudflare Workers + D1 работают без постоянно включённого компьютера;
  Telegram использует webhook, Windows polling отключён.
- Секреты находятся в Cloudflare Secrets, не в GitHub. Синхронизация
  выполняется официальным Wrangler stdin из локальной памяти ПК.
- Безопасность заказов: одновременное списание всех вариантов, защита от
  повторного подтверждения, версионирование предложений, SQLite-триггеры
  для атомарной отмены и точного восстановления остатков.
- Витрина Mini App: каталог, варианты, корзина, оформляемый администратором
  тестовый заказ, заявка на индивидуальный пошив.
- Панель администратора: разделы заказов, каталога, экономики и настроек
  продавца. Доступ — только с проверкой подписанного Telegram initData
  (HMAC-SHA256 и ограничение срока действия).
- Добавление/редактирование товаров, вариантов, цен, себестоимости и остатков.
  Фотографию изделия можно загрузить администратору через
  `/photo ID` в Telegram; клиентская витрина получает изображение через
  серверный прокси, без раскрытия BotFather токена.
- Индивидуальные заявки: описание, мерки, контакты, до четырёх фотографий
  через бот, смета с версией и кнопки согласования.
- Excel-отчёт, ручной учёт финансов, метрики дохода и остатков.
- Ежедневная очистка устаревших технических записей:
  Telegram update IDs старше 14 суток, сессии старше 30 суток,
  ключи повторных запросов старше 90 суток.
- Страница демо-условий: `/privacy`; команда `/forgetme` стирает
  контакты и референсы закрытых заказов.
- Отдельное разрешение на реальную торговлю **не выдано**:
  `DEMO_MODE=1` и `STORE_READY=0`. Включить реальную торговлю
  случайным снятием только одного переключателя нельзя.

## Необходимо от владельца бизнеса

- [ ] Название реального продавца, правовой статус и регистрационные данные.
- [ ] Настоящий ассортимент: названия, фотографии, размеры, SKU, цены,
      себестоимость и доступное количество.
- [ ] Контакты, пункт самовывоза/доставка, география и стоимость, сроки.
- [ ] Проверенные условия возврата/обмена, полной публичной оферты и
      обработки персональных данных под применимую юрисдикцию.
- [ ] Решение о приёме платежей: например официальный платёжный провайдер
      с аккаунтом продавца. Сейчас `/payment` — **только ручной учёт**,
      деньги не переводятся.
- [ ] Согласовать срок хранения персональных данных, независимые
      резервные копии и порядок обработки запросов на удаление.

## Обязательная приёмка перед открытием продаж

- [ ] Отдельный Telegram-покупатель оформляет каталог, отмену и заявку;
      администратор подтверждает статусы и сметы.
- [ ] Подключение реального Telegram Mini App на iOS/Android проверено
      настоящим `initData`, включая административный доступ.
- [ ] Проверены браузер, адаптивный дизайн, реальные фото, недоступность
      административных функций анонимному пользователю.
- [ ] Проверены параллельные покупки, повторная доставка Telegram updates,
      сетевые сбои Cloudflare/Telegram, отмены после возврата платежей.
- [ ] Протестированы резервное восстановление D1 и контроль полноты данных.
- [ ] Внешние юридические условия и платежи утверждены собственником.
- [ ] После всех проверок в **отдельном согласованном релизе**
      установить `DEMO_MODE=0` и `STORE_READY=1`.

## Операционные процедуры

- Проверка состояния: `.venv\\Scripts\\python.exe scripts\\verify-cloudflare.py`
- Wrangler: `cd cloudflare && npx wrangler@4.156.0 deploy`
- Точка восстановления D1: `wrangler d1 time-travel info atelier-customwear-demo-2026`
  (Time Travel включён автоматически, доступный период определяется тарифом).
- Возврат на Windows: `.venv\\Scripts\\python.exe scripts\\rollback-cloudflare.py`.
  **Не запускайте одновременно webhook и Windows polling**.
- Заказы и контакты не копировать в публичный GitHub, Jira/issues,
  GitHub Actions artifacts и общедоступные логи.
- Изменения D1 хранить в `cloudflare/migrations/`; миграции тестировать
  локально на SQLite перед применением к работающей базе.

Текущая версия является работающим **демонстрационным MVP**, не готовой
электронной торговой площадкой с настоящим эквайрингом.
